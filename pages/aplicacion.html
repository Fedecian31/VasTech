Aplicaciones VasTech

Mosquito Gym + Bosco se comercializa como un único producto y utiliza una sola aplicación. Mosquito Básquet funciona con una aplicación separada y Mosquito Pádel contará con su propia aplicación.

Importante

  • Gym y Bosco forman un único producto y utilizan la misma aplicación.
  • Básquet funciona con una aplicación independiente.
  • Pádel tendrá una aplicación independiente próximamente.

Mosquito Gym + Bosco

Mosquito Gym + Bosco se vende como una única solución que incluye ambos módulos. Desde una misma aplicación podés controlar las evaluaciones de fuerza, movimiento y saltabilidad.

Con esta solución podés

  • Analizar ejercicios de fuerza con el módulo Gym.
  • Realizar evaluaciones de salto con el módulo Bosco.
  • Control y gestión de las sesiones desde el celular.
Descargar según mi dispositivo Google Play App Store

Mosquito Básquet

Mosquito Básquet cuenta con una aplicación propia, separada de Gym y Bosco, pensada específicamente para el análisis técnico del tiro y la gestión de sesiones de lanzamiento.

Esta aplicación se utiliza para

  • Gestionar sesiones de tiro.
  • Seleccionar el tipo de análisis.
  • Consultar los videos y resultados registrados.
Descargar según mi dispositivo Google Play App Store

Mosquito Pádel

Mosquito Pádel funciona con una aplicación propia, desarrollada específicamente para el análisis de golpes y correcciones técnicas dentro de la cancha.

Estado de la aplicación

Próximamente disponible para Android y iPhone.
